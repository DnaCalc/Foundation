# OxReplay Bootstrap Templates

This directory contains the first starter-doc pack for the future `OxReplay` repo.

## Included
1. Repo root docs:
   - `README.md`
   - `CHARTER.md`
   - `OPERATIONS.md`
   - `AGENTS.md`
2. Starter mutable spec set:
   - `docs/spec/README.md`
   - `docs/spec/OXREPLAY_SCOPE_AND_BOUNDARY.md`
   - `docs/spec/OXREPLAY_ADAPTER_AND_CONFORMANCE_MODEL.md`
   - `docs/spec/DNA_RECALC_HOST.md`

## Intended use
1. Copy these files into a new `OxReplay` repo.
2. Treat them as the initial local doctrine and mutable spec seed.
3. Keep Foundation as the higher-precedence doctrine source.

## Not included in this pass
1. Repo-init script
2. CI scaffolding
3. Package/project file templates
4. Adapter code skeletons
