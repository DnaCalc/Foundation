# Welcome to the Microsoft Office Word 2003 XML Software Development Kit (SDK) [Word 2003 XML Reference]

Word 2003 XML software development kitWord XML content development kitWordmlWord SDK Documentation

Welcome to the Microsoft Office Word 2003 XML Software Development Kit (SDK), This reference contains conceptual overviews, programming tasks, samples, and references to guide you in developing solutions based on the Word SDK.

Publish date of this reference: January 2010 (version 2003)

[Download the Microsoft Office Word 2003: Software Development Kit](http://r.office.microsoft.com/r/rlidawscontentredir?assetid=xt011594831033&amp;ctt=11&amp;origin=hv011471701033)

Is the Word XML SDK for you? To find out more, read [Microsoft Office Word 2003 XML Software Development Kit (SDK) Overview](aa223586%28v=office.11%29) to find out.

This documentation contains the following sections:

- **[Getting Started](ee364544%28v=office.11%29)** Provides the essential information for working with XML in Office Word 2003.
- **[Concepts](aa223510%28v=office.11%29)** Provides information about XML development and advanced XML support in Office Word 2003.
- **[Reference](aa212812%28v=office.11%29)** Provides reference materials for the XML schema reference including descriptions of elements and types.
- **[Samples and Tools](aa212883%28v=office.11%29)** Provides samples of XML solutions and tools related to XML development in Office Word 2003 .
