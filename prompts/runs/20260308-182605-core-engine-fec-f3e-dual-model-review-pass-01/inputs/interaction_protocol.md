# Interaction Protocol: Base + Two Self-Review Iterations

Use the same process for each model lane.

1. Generate a full answer to `inputs/base_prompt.md`.
2. Self-review round 1:
   - Critique your own answer for correctness, coherence, missing obligations, and weak assumptions.
   - Produce a revised full answer.
3. Self-review round 2:
   - Critique the revised answer again with the same rigor.
   - Produce a final revised full answer.

Rules:
- Keep the core objective and deliverable order from the base prompt.
- You may inspect additional repository files outside the compact pack if needed.
- If extra files are used, cite them explicitly.
- Preserve deterministic, contract-level precision over narrative prose.
