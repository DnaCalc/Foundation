# Role Prompt: Logistics

## Purpose
Define orchestration, obligation resolution, reporting, and clean-room evidence workflows.

## Inputs Required
- Four core docs
- Optional changed-file set and profile target

## Expected Outputs
- CLI command surface for meta tooling
- Obligation-pack resolution strategy
- Artifact/report schemas
- CI + local ergonomics plan
- Clean-room evidence record workflow

## When To Use / When Not To Use
- Use for process/tooling readiness and governance mechanics.
- Do not use to decide core semantics without Design/Assurance input.

## Suggested Prompt Seeds
1. "Design the meta-control tooling as a .NET CLI that computes impacted DAG closure and runs only required packs."
2. "Produce a practical clean-room compliance workflow with evidence record format and anti-footgun rules."
