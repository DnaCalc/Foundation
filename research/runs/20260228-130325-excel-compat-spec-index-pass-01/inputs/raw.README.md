# inputs/raw (removed 2026-10-30)

This folder held 70 raw HTML copies of Microsoft web pages (59 from support.microsoft.com, 10
from learn.microsoft.com, 1 from techcommunity.microsoft.com) captured on 2026-02-28 as the
inputs of this run. They were removed (DnaCalc dc-96l.4 and dc-96l.5): support.microsoft.com is
under Microsoft's Terms of Use, which grant no licence to republish its pages, and the others were
whole-page copies with site chrome. The run's outputs keep the URLs (`outputs/source_list.csv`,
`outputs/source_digest.csv`), from which each page can be fetched again.
