# Topic Context

## Run Framing
This run treats the current `OxCalc`, `OxFml`, `OxFunc`, and `OxVba` repositories as authoritative for lane-owned semantics, runner contracts, replay fixtures, evidence surfaces, and conformance artifact models.

Foundation doctrine remains the framing authority for:
1. mission and doctrine,
2. architecture-independent constraints,
3. managed-run discipline,
4. pack and evidence expectations.

Foundation mirror copies are not treated as canonical where sibling repos now own the editable spec surface.

## Why This Run Exists
The current program already contains several partially convergent replay directions:
1. `OxCalc` now has `TraceCalc`, a self-contained scenario schema, validator-runner contract, and reference-machine oracle direction.
2. `OxFml` now has explicit artifact identities, minimum seam schemas, typed trace and reject taxonomies, and fixture-family replay planning.
3. `OxFunc` now has manifest-driven empirical replay, stable local evidence ids, dual-run compatibility labeling, and explicit boundary-invariant discipline.
4. `OxVba` now has runner policy fingerprints, clause-catalog conformance, deterministic artifact emission, and evidence-heavy host/COM/formal lanes.

What is missing is a single cross-lane Replay appliance contract that:
1. preserves lane ownership,
2. normalizes portable replay bundles,
3. supports replay, diff, and explain workflows,
4. provides a shared tool surface for packs, conformance, and cross-engine triage.

## Authoritative Input Rule Used In This Run
When this run names a lane contract, it is derived from the current sibling repo docs listed in `outputs/source_list.csv`.

When this run proposes a shared Replay appliance rule, it follows these constraints:
1. it must not silently redefine lane-owned semantics,
2. it must be implementable through lane adapters and bundle projection,
3. it must preserve deterministic replay, typed rejects, and pack-grade artifact discipline,
4. it must respect current repo ownership and proving-host boundaries.
